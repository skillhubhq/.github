### One community. Your infrastructure.

SkillHub brings a Web community, a desktop app and a CLI together around a shared Go core. Run a Hub for your team, or connect to several independent Hubs from your own machine.

| Discover | Share responsibly | Make it useful |
| --- | --- | --- |
| Browse skills, authors and team collections. | Review submissions and control access with roles, namespaces and groups. | Install into Codex or Claude Code, globally or per project. |
| Save useful versions and join discussions. | Keep identities and permissions separate for every Hub. | Preview file changes, pin versions and protect local edits. |

**Lightweight by design:** one Go service, an embedded Web UI, SQLite or PostgreSQL, and local package storage. SkillHub manages skill files; it does not run agents or execute package scripts.
